# 한글맞춤법 마스터

**배우고, 도전하고, 성장하는 맞춤법 교실**  
중·고등학생을 위한 현대적인 디지털 한글맞춤법 학습 및 게이미피케이션 평가 웹 프로그램입니다.  
“올바른 맞춤법은 정확한 의사소통의 시작입니다.”

---

## 1. 프로그램 제작 목적 및 학습 대상
- **학습 대상**: 중학생·고등학생 (수업 보조 자료, 자기 주도 학습, 방과 후 보충 학습용)
- **제작 목적**:
  - 일상생활과 학업에서 자주 혼동하는 맞춤법의 기본 원리를 이해합니다.
  - 유형별 개념 학습(규칙, 비교, 예문, 꿀팁)을 통해 체계적으로 기초를 다집니다.
  - 선택형 퀴즈(36문항)와 직접 수정 퀴즈(18문항)로 문법 지식과 정확한 표기 능력을 체득합니다.
  - **게이미피케이션(연속 정답 & 6대 성취 배지)**을 통해 경쟁과 순위 부담 없이 자신의 성장과 성취감을 만끽하며 자발적인 학습 동기를 부여합니다.
  - **맞춤형 학습 결과 분석 및 취약 유형 추천 엔진(8단계 완성)**을 통해 실제 응답 데이터를 기반으로 취약 유형을 진단받고, 묶음 집중 학습으로 약점을 완벽히 보완합니다.
  - 오답 노트와 오답 집중 학습으로 틀린 문항을 스스로 극복합니다.

---

## 2. 개발 환경 및 사용 기술
- **기술 스택**: HTML5, CSS3, Vanilla JavaScript (외부 프레임워크, 라이브러리, 빌드 도구 미사용)
- **인터넷 독립성**: 외부 웹폰트, CDN, AI API, 차트 라이브러리, DB를 일체 사용하지 않으며 로컬 단독 환경에서 100% 작동합니다.
- **인코딩 및 언어**: UTF-8, `<html lang="ko">`
- **보안 및 접근성**:
  - 사용자 입력값은 `textContent` 및 안전한 DOM API로 렌더링하여 XSS를 원천 차단합니다.
  - 학생 간 순위 경쟁, 공개 랭킹, 생명력 차감, 제한 시간 등 학습 부담 요소를 철저히 배제했습니다.
  - `prefers-reduced-motion` 미디어 쿼리를 지원하여 애니메이션을 선호하지 않는 학생에게 정적인 화면을 제공합니다.
  - 색상에만 의존하지 않고 모든 상태를 텍스트('획득 완료' / '미획득', 성취 등급 텍스트)로 병행 제공합니다.
  - 시각 장애 및 스크린 리더 사용자를 위해 원형 도넛 차트에 `role="img"` 및 상세한 `aria-label`을 적용했습니다.

## 3. 전체 프로젝트 파일 구성

| 파일명 | 역할 및 내용 |
|---|---|
| `index.html` | 전체 프로그램 구조 및 8대 화면(메인 대시보드, 선택형 퀴즈, 직접 수정 퀴즈, 성취 배지 보관함, 결과, 오답 노트, 개념 목록, 개념 상세) |
| `style.css` | 디자인 시스템, 대시보드 카드 그리드, 성취 배지 카드, 연속 정답 불꽃 뱃지/토스트, 원형 도넛 차트(`conic-gradient`), 맞춤 추천 카드 그리드, 반응형 레이아웃 |
| `questions.js` | 선택형 36문항 데이터 (`window.QUESTIONS`) 및 검증 함수 (`window.validateQuestions`) |
| `concepts.js` | 9개 유형별 개념 학습 데이터 (`window.SPELLING_CONCEPTS`) 및 검증 함수 (`window.validateConcepts`) |
| `writing-questions.js` | 직접 입력형 18문항 데이터 (`window.WRITING_QUESTIONS`) 및 검증 함수 (`window.validateWritingQuestions`) |
| `achievements.js` | 6대 성취 배지 정의 및 메모리 기반 배지 평가·보존 관리자 (`window.AchievementManager`) |
| `analytics.js` | **8단계 신규**: 교육 데이터 분석 및 맞춤 추천 엔진 (`window.SpellingAnalytics`) |
| `script.js` | 세션 관리, 연속 정답 추적, 한글 IME 조합 처리, 자동 채점, 오답 노트, 도넛 차트 렌더링, 추천 유형 묶음 학습, 개념-결과 화면 간 네비게이션 복귀 |
| `README.md` | 프로그램 종합 설명 및 사용 설명서 |
| `TEST_REPORT.md` | **8단계 신규**: 전 단계 통합 QA 및 헤드리스 브라우저 테스트 검증 리포트 |

- **스크립트 로딩 순서**: `questions.js` → `concepts.js` → `writing-questions.js` → `achievements.js` → `analytics.js` → `script.js` (모두 `defer` 속성 적용)
- **백업 디렉터리**: `.backup_step4/`, `.backup_step5/`, `.backup_step6/`, `.backup_step7/`

## 5. 주요 학습 및 분석 기능 (1~8단계 완성)

### ① 메인 대시보드 메뉴
1. **맞춤법 개념 학습**: 9가지 맞춤법 유형의 세부 규칙, 원리 비교 및 생생한 예문 학습
2. **전체 선택형 퀴즈 (36문항)**: 전체 선택형 문항 무작위 출제
3. **유형별 선택형 퀴즈**: 9개 유형 중 원하는 유형만 집중 풀이
4. **직접 수정 퀴즈 (18문항)**: 밑줄 친 오탈자를 키보드로 직접 입력해 고치기 (전체 18문항 또는 유형별 2문항)
5. **나의 성취 배지 (6종)**: 학습 목표를 달성하며 모은 성취 배지 보관함
6. **오답 집중 학습**: 직전 학습의 오답만 모아 재도전
7. **최근 학습 결과 바로보기 배너**: 학습 완료 후 홈 화면에서 직전 학습 분석 리포트로 즉시 재이동 가능

### ② 8단계 교육 데이터 분석 및 맞춤형 추천 시스템 (`analytics.js`)
- **원형 도넛 점수 차트**: 순수 CSS `conic-gradient`를 활용하여 반올림 전 실제 정답률 각도로 채워지며, 중앙에 직관적인 반올림 종합 점수가 표출됩니다.
- **맞춤형 취약 유형 추천 알고리즘 (10대 원칙)**:
  1. 실제 응답 데이터 기반: 한 번이라도 오답이 발생한 유형 중 정답률 70% 미만인 유형을 1차 선별합니다.
  2. 70% 미만 유형이 없더라도 오답이 있다면, 오답 발생 유형 중 최저 정답률 유형을 선정합니다.
  3. 실제 정답률 낮은 순(오름차순) → 오답 수 많은 순(내림차순) → 9개 정규 유형 순서 순으로 엄격 정렬합니다.
  4. 메인 화면에 상위 최대 3개의 추천 카드를 배치하고, 4개 이상일 경우 '추가 추천 유형' 영역에 정돈하여 표시합니다.
  5. 모든 문항을 맞힌 만점 세션의 경우 취약 유형을 억지로 추천하지 않고, 황금 트로피와 함께 만점 축하 메시지를 표시합니다.
- **추천 카드 3대 학습 액션**:
  - `📖 개념 다시 학습하기`: 해당 유형의 개념 상세 화면으로 이동하며, 복습 후 다시 결과 화면으로 손쉽게 돌아올 수 있는 '결과 화면으로 돌아가기' 버튼을 제공합니다.
  - `🎯 선택형 집중 학습`: 해당 유형의 선택형 문제를 즉시 집중 풀이합니다.
  - `✍️ 직접 수정 연습하기`: 해당 유형의 직접 입력형 문제를 즉시 집중 연습합니다.
- **추천 유형 한 번에 학습하기**: 추천된 취약 유형들의 문항들만 한데 모아 직전 모드(선택형/직접입력형)에 맞춘 새로운 집중 학습 세션을 원클릭으로 생성합니다.
- **유형별 성취도 분석 리스트**: 가로 막대 그래프와 함께 정답률(소수점 1자리), 정답/전체 수, 성취 등급 태그(완벽/우수/보완 필요/집중 필요)를 제공하며, 출제 문항 수가 3개 이하인 유형은 '소량 문항 (참고용)' 뱃지를 표시합니다.

### ③ 게이미피케이션 요소
- **연속 정답(Streak) 시스템**: 퀴즈 화면 상단 불꽃 뱃지(🔥) 및 단계별 격려 토스트 (2, 3, 5, 10, 15연속).
- **6대 성취 배지 (`AchievementManager`)**:
  - `첫걸음`(🌱), `연속 정답 챔피언`(🔥), `정확한 한글`(🎯), `한글 탐험가`(📖), `오답 정복`(🔄), `맞춤법 마스터`(🏆).
  - 학습 평가 점수와 게이미피케이션 점수를 분리하여 교육적 신뢰성을 유지합니다.
